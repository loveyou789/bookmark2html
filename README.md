# 书签分类器 · Chrome 书签自动分类（单文件 Demo）

## 这是什么

一个**自包含单 HTML 文件**的纯前端工具：把 Chrome 书签导出文件拖进去，自动按类别整理、搜索、筛选，并可一键导出「已按类别整理好的书签 HTML」。

- 零依赖：无 CDN、无在线字体、无外部 API，双击 HTML 即可离线使用。
- 隐私安全：解析、分类、渲染、导出全部在浏览器本地完成，数据不上传。
- 内置「示例数据」按钮：不导出自己的书签也能先看效果（示例数据会在页面顶部明确标注）。

## 怎么用（真实数据）

1. 打开 Chrome，按 `Ctrl+Shift+O`（Mac：`Cmd+Option+B`）打开书签管理器。
2. 右上角「⋮」菜单 → **导出书签**，得到一个 HTML 文件。
   （另一条路：直接复制 Chrome 配置目录下的 `Bookmarks` JSON 文件，本页同样支持。）
3. 打开本页，把文件拖进虚线框（或点「导入书签文件」）。
4. 浏览分类结果、搜索、按分类筛选；点「导出分类结果 HTML」下载整理好的版本。

## 支持的输入格式

| 格式 | 来源 | 说明 |
| --- | --- | --- |
| Netscape 书签 HTML | Chrome 书签管理器「导出书签」 | 主路径，兼容嵌套文件夹、HTML 实体、ADD_DATE/ICON 等属性 |
| Chrome Bookmarks JSON | Chrome 配置目录 `User Data/Default/Bookmarks` | 兼容 bookmark_bar / other / synced 三个根 |

## 自动分类机制

两级规则，均为本地纯函数：

1. **域名规则**：内置 12 类 × 数百个常见站点域名（含子域名后缀匹配），优先命中。
   类别：AI 工具 / 开发工具 / 技术文档与学习 / 社交社区 / 视频与娱乐 / 新闻资讯 / 购物电商 / 设计与素材 / 办公与效率 / 金融理财 / 生活服务 / 其他。
2. **文件夹名提示**：域名未命中时，根据书签所在文件夹名（如「购物」「理财」「摸鱼」）推断类别。
3. 均未命中 → 归入「其他」。

## 布局与搜索（v3 按反馈更新）

- 每个分类的书签网格改为**自适应列数**：`repeat(auto-fill, minmax(165px, 1fr))`，按屏幕尺寸自动增减列数（1280px 桌面约 6 列、640px 约 3 列、390px 手机 2 列），卡片保持紧凑。
- 主页面搜索框**吸顶**（sticky），滚动浏览长列表时始终可用。
- **导出的 HTML 同样带搜索框**：输入即过滤，实时显示匹配数，无命中的分类自动隐藏；同样为自适应网格。

## 编辑功能（v3/v4）

- **右键拖拽移动**：在书签卡片上按住鼠标右键拖动，目标分类会虚线高亮，松开即把该书签移入该分类（手动分类优先于自动规则；按 Esc 可取消拖拽）。
- **删除（可撤销）**：悬停卡片点右上角 × 删除，toast 中提供「撤销」按钮恢复。
- **新增书签**：点「＋ 新增书签」填写标题/网址/分类即可手动补充；网址自动补 `https://` 前缀并校验格式、查重。
- **自定义分类（v4 新增）**：点「＋ 新增分类」输入名称即可创建自己的分类（自动分配颜色、与内置分类查重）。自定义分类：
  - 空分类也会显示占位区块，可直接把书签右键拖入，或新增书签时选择它；
  - 排在内置分类之后、「其他」之前；导出时自动跳过空的自定义分类；
  - 分类标题右侧有 ✕，点击删除该分类——其中的书签自动回到规则分类（如 GitHub 回「开发工具」），toast 可撤销整体恢复。
- **自动保留**：所有编辑（移动/删除/新增/自定义分类）与导入的数据自动存入浏览器 localStorage，**刷新页面不丢失**；点「清空重来」可一键清空全部数据回到初始状态。
- 编辑是**覆盖层**设计：原始导入数据不被改动，随时可通过「清空重来」回到导入时的原样。

已知边界：仅凭 URL + 标题分类（不抓取页面内容），冷门小站可能落入「其他」；后续可升级为 AI 语义分类兜底。

## 文件结构

- `index.html` —— 全部源码（HTML + CSS + JS 单文件）。核心逻辑位于 `/* CORE-START */` 与 `/* CORE-END */` 标记之间，可在 Node 中直接提取测试。
- `tests/test-core.mjs` —— 核心逻辑测试（Node 运行，不需要浏览器）。

## 本地验证

```bash

node tests/browser-check.mjs  # 浏览器端到端测试（75 项，需系统 Chromium + puppeteer-core）
```

核心测试覆盖：Netscape 嵌套文件夹解析、HTML 实体解码、根目录名剥离、Bookmarks JSON 解析、域名分类（含子域名）、文件夹提示分类、未命中兜底「其他」、手动分类覆盖优先于规则、自定义分类（空也保留、位于其他之前、导出跳过空分组）、导出 HTML 内容与自适应网格。

浏览器测试覆盖：拖拽导入、示例数据、自适应网格（1280/640/390px 三档）、搜索、筛选、折叠、导出页过滤、新增书签（含空值拦截）、右键拖拽移动、删除与撤销、刷新保留、**自定义分类全链路（创建/查重/占位/归入/拖入/删除回退/撤销/刷新保留）**、清空重来、390px 窄屏、键盘可达、控制台零报错。

## 已知限制

- 分类规则面向中文用户常见站点，不做页面内容级语义理解。
- 单分类卡片渲染上限 200 条（防卡顿），搜索可缩小范围，导出不受限。
- 图标用域名首字母彩色占位，不加载在线 favicon（保证完全离线）。
